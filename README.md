Dynamic Product Catalog

A modern, dynamic e-commerce product catalog built with React, TypeScript, Redux, and TailwindCSS.
This project simulates a real-world e-commerce application where users can browse, filter, sort, and explore products with seamless performance and responsiveness.

🚀 Features

API Data Integration – fetches products dynamically from FakeStore API
.

Filtering & Sorting – category filtering, price-based sorting, and multi-criteria filters.

Pagination & Infinite Scrolling – optimized for high-traffic scenarios.

Responsive UI – works seamlessly across desktop, tablet, and mobile devices.

State Management – powered by Redux Toolkit for predictable and scalable state handling.

Type Safety – built with TypeScript for maintainability.

🛠️ Tech Stack

React + Vite – fast, modern frontend tooling

TypeScript – type-safe and maintainable code

Redux Toolkit – efficient state management

TailwindCSS – utility-first responsive styling

Axios – API data fetching
